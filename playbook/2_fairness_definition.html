Step 1: Historical Context Assessment

Has historical context analysis revealed systematic exclusion or under-representation of protected groups?

  • yes: Include demographic parity as a required fairness definition, then proceed to Step 2
  • no: Proceed directly to Step 2.

Step 2: Error-Impact Analysis

Which error type has greater negative impact in this application?

  • If false negatives (FN) are more harmful: Make equal opportunity a mandatory fairness definition.
  • If false positives (FP) are more harmful: Make predictive equality a mandatory fairness definition.
  • If both error types are equally critical: Make equalized odds a mandatory fairness definition.

Step 3 : Outcome Calibration Assessment

Will the system expose probabilistic scores to users or analysts (e.g., credit-risk scores, insurance pricing, ranking algorithms)?

  • yes: Add sufficiency (group-calibrated scores) to your fairness metric set.
  • no: Use the definitions selected in the previous steps.

Step 4 : intersectionality considerations

  • Methodological complexity in modeling multiple, interacting protected attributes.
  • Statistical challenges with smaller sample sizes at demographic intersections.
  • Computational difficulties in analyzing all possible demographic subgroups.
